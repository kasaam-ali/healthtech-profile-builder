# Week 3 model comparison

Recreate: `cd backend && python -m scripts.train_ml` (writes `backend/ml/artifacts/metrics.json`).

- Split: stratified 75/25 `train_test_split`, `random_state=42`.
- Leakage control: scaler and encoder live inside each sklearn `Pipeline` and are fit on the training split only. Test rows are used only for scoring.
- Selection rule: highest F1 on the held-out test split.

| Model | Precision | Recall | F1 | Confusion [[TN, FP], [FN, TP]] |
|---|---|---|---|---|
| Logistic Regression (max_iter=1000) | 0.7437 | 0.7080 | 0.7254 | [[189, 61], [73, 177]] |
| Random Forest (200 trees, max_depth=8) | 0.7489 | 0.6680 | 0.7061 | [[194, 56], [83, 167]] |

**Chosen:** Logistic Regression, saved as `engagement-v1.0.0` in `backend/ml/artifacts/engagement_model.joblib` (preprocessing + estimator in one pipeline, about 4 KB). It wins on F1 and recall and is easier to explain; the synthetic label was generated by a logistic rule, so this is expected.

## Notes
- Random Forest has slightly higher precision; if false positives mattered more it could be chosen instead.
- Numbers are on synthetic data and are not evidence of real world performance.
