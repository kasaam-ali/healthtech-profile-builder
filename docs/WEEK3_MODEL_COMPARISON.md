# Week 3 model comparison

Recreate: `cd backend && python -m scripts.train_ml` (writes `backend/ml/artifacts/metrics.json`).

- Split: stratified 75/25 `train_test_split`, `random_state=42` (1500 train rows, 500 test rows).
- Leakage control: scaler and encoder live inside each sklearn `Pipeline`, so every CV fold and the final fit learn preprocessing from their own training rows only.
- **Selection rule (changed after the PR #4 review):** highest mean F1 in 5-fold stratified cross-validation on the training split only (`StratifiedKFold`, shuffle, `random_state=42`). The test split is not used for selection.
- Final report: the chosen pipeline is refit on the full training split and scored once on the 25% test split, next to a prevalence baseline.
- Baselines: `dummy_always_engaged` (`DummyClassifier(strategy="constant", constant=1)`, always predicts the positive class; positive rate is about 50%) and `dummy_stratified` (random guesses at the class prior, seed 42). Baselines are never selectable.

## Selection evidence: 5-fold CV on the training split

| Model | CV F1 (mean +/- std) | CV precision | CV recall | CV accuracy |
|---|---|---|---|---|
| Logistic Regression (max_iter=1000) | 0.7491 +/- 0.0194 | 0.7489 | 0.7497 | 0.7487 |
| Random Forest (200 trees, max_depth=8) | 0.7323 +/- 0.0234 | 0.7438 | 0.7218 | 0.7360 |
| Dummy: always engaged (prevalence) | 0.6673 +/- 0.0012 | 0.5007 | 1.0000 | 0.5007 |
| Dummy: stratified random | 0.4867 +/- 0.0227 | 0.4972 | 0.4767 | 0.4967 |

## Final held-out test report (500 rows, not used for selection)

| Model | Precision | Recall | F1 | Accuracy | Confusion [[TN, FP], [FN, TP]] |
|---|---|---|---|---|---|
| Logistic Regression (chosen) | 0.7437 | 0.7080 | 0.7254 | 0.7320 | [[189, 61], [73, 177]] |
| Dummy: always engaged (prevalence) | 0.5000 | 1.0000 | 0.6667 | 0.5000 | [[0, 250], [0, 250]] |

**Chosen:** Logistic Regression, saved as `engagement-v1.1.0` in `backend/ml/artifacts/engagement_model.joblib` (preprocessing + estimator in one pipeline). It wins on CV F1 and is easier to explain; the synthetic label was generated by a logistic rule, so this is expected.

## Notes
- The test figures for Logistic Regression are the same as the earlier `engagement-v1.0.0` report because the train/test split and the estimator settings did not change. What changed is that the test split no longer informs the choice, so it is now an unbiased final report.
- The earlier version of this report ("LR F1 0.7254 vs RF 0.7061") compared both models on the test split and used that comparison to select. Those numbers should be read as selection evidence, not as an independent test result.
- The improvement over the prevalence baseline is real but modest on F1 (0.7254 vs 0.6667); on accuracy it is clearer (0.732 vs 0.500). An always-positive model gets high F1 cheaply when classes are balanced, which is why both metrics are shown.
- Random Forest has slightly lower CV F1 and a higher fold-to-fold spread.
- Numbers are on synthetic data and are not evidence of real world performance.
