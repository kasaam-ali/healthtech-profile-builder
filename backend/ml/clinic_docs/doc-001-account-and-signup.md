title: Account and Signup Policy
---
Members create an account with an email address, a full name, and a password of at least 8 characters. Each email address can be registered only once.

Admin accounts cannot be created through public signup. Admin access is granted only by the Northwind Wellness Clinic operations team and uses a separate admin login.

Access tokens expire after 15 minutes. Refresh tokens last 7 days. Members can log out at any time, which ends the current session.
